# 🚀 NexaCRM

A modern SaaS CRM landing page built with **HTML, CSS, and Vanilla JavaScript**. NexaCRM simulates a complete **WordPress Admin Dashboard**, **Theme Customizer**, **Blog Manager**, and **CRM Pipeline**, all running entirely in the browser with **no backend required**.

## ✨ Features

* Responsive SaaS Landing Page
* Interactive Dashboard & Analytics
* WordPress Admin Simulation
* Live Theme Customizer
* Blog Post Management
* Media Library & Comments Manager
* CRM Kanban Pipeline
* Lead & Deal Tracking
* LocalStorage Persistence
* Authentication Simulation

## 🛠 Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* LocalStorage
* Canvas API
